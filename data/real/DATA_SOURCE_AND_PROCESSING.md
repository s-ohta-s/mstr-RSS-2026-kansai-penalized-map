# `transformed_data198_for_R.csv` の出典と作成方法

## 1. データの概要

`transformed_data198_for_R.csv` は、総務省統計局「社会・人口統計体系」の市区町村データを基に作成した、2 時点のパネルデータです。近畿地方の 198 市町村について、人口の高齢化と産業構成を表す 2 変数を目的変数とし、所得、外国人人口、人口移動および通勤流入に関する 4 変数を説明変数として収録しています。

この CSV は、政府統計として公表された原データそのものではなく、分析のために変数の抽出、対数変換、標準化および列名の変更を行った加工データです。

| 項目 | 内容 |
|---|---|
| 出力ファイル | `transformed_data198_for_R.csv` |
| 空間単位 | 滋賀県、京都府、大阪府、兵庫県、奈良県、和歌山県の全 198 市町村 |
| 時点 | 2015年度、2020年度 |
| データ形式 | long 形式のバランスド・パネル |
| 観測数 | 396 行（198 市町村 × 2 時点） |
| 変数数 | 8 列（地域・時点 2 列、分析変数 6 列） |
| 欠測値 | なし |

府県別の市町村数は、滋賀県 19、京都府 26、大阪府 43、兵庫県 41、奈良県 39、和歌山県 30 です。

## 2. データの出典

社会・人口統計体系は、人口・世帯、自然環境、経済基盤、行政基盤、教育、労働、居住、健康・医療、福祉・社会保障など、国民生活全般の実態を示す地域別統計データを収集・加工し、体系的に整備したものです。詳細は、総務省統計局の[「統計でみる都道府県・市区町村のすがた」](https://www.stat.go.jp/data/ssds/index.html)を参照してください。

本データで使用した e-Stat の統計表は次の 3 表です。

| 表番号 | 表題 | 本データで使用した指標 |
|---|---|---|
| [0000020301](https://www.e-stat.go.jp/dbview?sid=0000020301) | Ａ　人口・世帯 | 65歳以上人口割合、外国人人口（人口10万人当たり）、転入超過率（日本人移動者） |
| [0000020304](https://www.e-stat.go.jp/dbview?sid=0000020304) | Ｄ　行政基盤 | 課税対象所得（納税義務者1人当たり） |
| [0000020306](https://www.e-stat.go.jp/dbview?sid=0000020306) | Ｆ　労働 | 第2次産業就業者比率、他市区町村からの通勤者比率 |

原データの取得日は **2026年7月3日** です。e-Stat 上の統計表は更新されることがあるため、後日取得した値とは異なる可能性があります。e-Stat のデータを利用する際は、[政府統計の総合窓口（e-Stat）利用規約](https://www.e-stat.go.jp/terms-of-use)も参照してください。

### 2.2 対象地域と地域 ID

対象は、滋賀県、京都府、大阪府、兵庫県、奈良県および和歌山県の 198 市町村です。

出力列 `region` は、市区町村コードそのものではなく、分析用に 1 から 198 まで順番に付与した内部 ID です。市区町村コード・市区町村名との対応は、別途作成した地域 ID 対応表に記録しています。したがって、他のデータと結合するときは `region` を直接自治体コードとして扱わず、必ず対応表を介してください。

### 2.3 対象時点

e-Stat の調査年「2015年度」と「2020年度」を使用しています。出力 CSV では、分析用に次のように整数へ置き換えています。

| `time` | 調査年 |
|---:|---|
| 1 | 2015年度 |
| 2 | 2020年度 |

## 3. 使用した指標と変換

### 3.1 変数対応表

| 出力列 | モデル上の役割 | e-Stat 指標コード | e-Stat の指標名 | 原単位 | 出力値の作成方法 |
|---|---|---|---|---|---|
| `y1` | 目的変数 1 | `#A03506` | 65歳以上人口割合 | % | 2015・2020年度をプールして標準化 |
| `y2` | 目的変数 2 | `#F01202` | 第2次産業就業者比率 | % | 2015・2020年度をプールして標準化 |
| `x_common1` | 両方の式に入る共通説明変数 1 | `#D02206` | 課税対象所得（納税義務者1人当たり） | 千円 | 自然対数 `ln(x)` |
| `x_common2` | 両方の式に入る共通説明変数 2 | `#A01601` | 外国人人口（人口10万人当たり） | 人 | 自然対数 `ln(x + 1)` |
| `x_specific1_1` | 目的変数 1 の式に入る固有説明変数 | `#A05301` | 転入超過率（日本人移動者） | % | 無変換（e-Stat の値をそのまま使用） |
| `x_specific2_1` | 目的変数 2 の式に入る固有説明変数 | `#F02702` | 他市区町村からの通勤者比率 | % | 無変換（e-Stat の値をそのまま使用） |

`#A01601` は外国人の実人数ではなく、人口 10 万人当たりの外国人人口です。`x_common2` は、この人口 10 万人当たりの値に 1 を加えて自然対数を取ったものです。

また、% 表示の変数は 100 で割った比率には変換していません。たとえば、`x_specific2_1 = 23.5` は 0.235 ではなく 23.5% を意味します。

### 3.2 標準化

`y1` と `y2` は、各変数について 198 市町村 × 2 時点の 396 観測をまとめて用い、次式により標準化しています。

```text
z(i,t) = {x(i,t) - mean(x)} / sd_pop(x)
```

ここで `mean(x)` と `sd_pop(x)` は、それぞれ 396 観測全体の平均と母標準偏差です。標準偏差の分母は `N - 1` ではなく `N` です。年度別または市町村別の標準化ではありません。

### 3.3 対数変換

`x_common1` と `x_common2` の変換は次のとおりです。`ln` は自然対数を表します。

```text
x_common1 = ln(課税対象所得)
x_common2 = ln(外国人人口（人口10万人当たり） + 1)
```

`x_common2` に 1 を加えるのは、原値が 0 の観測にも対数変換を適用できるようにするためです。

## 4. データ作成手順

データ作成の流れは次のとおりです。

1. e-Stat の「社会生活統計指標（廃置分合処理済）」から、2015年度と2020年度の市区町村データを取得する。
2. 対象を近畿 2 府 4 県の 198 市町村に限定し、指標コード、指標名、2015年度値および2020年度値を整理する。
3. 6 指標を抽出し、`y1` と `y2` を 396 観測全体で標準化する。
4. `x_common1` を `ln(x)`、`x_common2` を `ln(x + 1)` に変換する。残る 2 つの説明変数には e-Stat の値をそのまま使用する。
5. 調査年を `time = 1`（2015年度）、`time = 2`（2020年度）へ置き換える。
6. 市町村ごとに `time = 1`, `time = 2` の順で並べ、long 形式の `transformed_data198_for_R.csv` を出力する。

## 5. 出力ファイルの列定義

出力 CSV の列順は次のとおりです。

```text
region,time,y1,y2,x_common1,x_common2,x_specific1_1,x_specific2_1
```

| 列 | データ型 | 内容 |
|---|---|---|
| `region` | integer | 市町村の内部 ID（1–198） |
| `time` | integer | 時点 ID（1 = 2015年度、2 = 2020年度） |
| `y1` | numeric | 標準化した65歳以上人口割合 |
| `y2` | numeric | 標準化した第2次産業就業者比率 |
| `x_common1` | numeric | 課税対象所得（納税義務者1人当たり）の自然対数 |
| `x_common2` | numeric | 外国人人口（人口10万人当たり）に 1 を加えた値の自然対数 |
| `x_specific1_1` | numeric | 転入超過率（日本人移動者）の原値（%） |
| `x_specific2_1` | numeric | 他市区町村からの通勤者比率の原値（%） |

各 `region` に `time = 1` と `time = 2` が 1 行ずつ存在します。`region` と `time` の組は一意です。

## 7. 利用上の注意

- 本データは、公的統計を研究・分析用に加工した二次データです。数値の定義を確認するときは、e-Stat の指標名、解説および原資料を参照してください。
- `region` は分析用 ID であり、市区町村コードではありません。
- `y1` と `y2` は標準化済みのため、元の % 単位ではありません。
- `x_common1` と `x_common2` は自然対数変換済みのため、元の千円または人数単位ではありません。
- e-Stat の「廃置分合処理済」データは、異なる時点の市区町村を一定時点の行政区域に合わせて整備したものです。行政区域の基準時点は、使用した e-Stat 公開版の説明を確認してください。
- 本データには欠測値はありません。ただし、これは採用した対象地域・時点・指標についての検査結果であり、e-Stat の統計表全体に欠測がないことを意味しません。
